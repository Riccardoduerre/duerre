## 🚀 3 STEPS TO LAUNCH

### Step 1️⃣: EmailJS Setup (5 min)
```
Go to: emailjs.com
- Sign up (free)
- Create service: service_duerre_prod
- Create template: template_contact_riccardo
- Get Public Key
- Update src/pages/Contact.tsx with your key
```

### Step 2️⃣: GitHub Pages (2 min)
```
Go to: GitHub Settings → Pages
- Set source: gh-pages branch
- (Optional) Add custom domain
```

### Step 3️⃣: Deploy (1 min)
```bash
npm run deploy:gh-pages
```
